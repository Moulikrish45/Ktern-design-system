### Design Principles

- **Grid:** 24×24px base size
- **Stroke:** 2px consistent weight
- **Corners:** 2px radius for soft feel
- **Structure:** `currentColor` for adaptability
- **Spark:** `#ff8f00` for the active element

### Icon Categories

#### Action & Intelligence
Icons representing AI-powered actions and core functionality.

#### Utility & System
Icons for common system operations and navigation.

#### Governance & Brand
Icons representing enterprise features and brand identity.
